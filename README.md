# VG+ | صندوق التواصل المباشر

الموقع يتكون من واجهة عامة على GitHub Pages، وخادم Cloudflare Workers / Sites وقاعدة D1 دائمة. لوحة الفريق تعمل على الخادم وتستخدم رموزاً مستقلة للأعضاء، دون حساب ChatGPT أو تسجيل عضوية عام.

## الروابط

- الواجهة: https://7madybar.github.io/---------------------/
- الخادم والواجهة البديلة: https://vg-visionary-feedback.clayimage8.chatgpt.site/
- لوحة الفريق: https://7madybar.github.io/---------------------/team/
- اللوحة المستقلة عند الحاجة: https://vg-visionary-feedback.clayimage8.chatgpt.site/admin

GitHub Pages يستضيف ملفات ثابتة فقط. لذلك لا يكفي رفع ملفات React/TypeScript إليه. ملف index.html ومجلد pages-assets يحتويان النسخة المبنية للمتصفح، وترسل البيانات إلى الخادم الحقيقي.

## تعديل الواجهة ونشرها على GitHub

1. ثبّت Node.js 22.13 أو أحدث، ثم `npm ci`.
2. عدّل ملفات app/components/CSS في المصدر.
3. نفّذ `npm run build:pages`.
4. أضف index.html وpages-assets و.nojekyll إلى commit مع تعديلات المصدر، ثم ادفع إلى فرع main. إعداد Pages الحالي ينشر من جذر هذا الفرع.
5. إعداد مسار المستودع وعنوان الخادم موجود في vite.pages.config.ts. الأصول تستخدم مسار المستودع الصحيح.

لا يعدّل بناء Pages الخادم تلقائياً. إذا غيّرت API أو الصلاحيات أو مخطط DB، ابنِ الخادم وانشره على Sites أيضاً. ملف scripts/build-github-pages.mjs يجعل الواجهة الثابتة مبنية من نفس مكونات المصدر، دون نسخة تصميم منفصلة.

## الخادم وقاعدة البيانات

.openai/hosting.json يعلن الربط DB. تهيئ Sites قاعدة D1 وتطبق ترحيلات drizzle عند النشر. الجداول تحفظ الرسائل والتعليقات والأعضاء وتجزئات الرموز والجلسات. بيانات التطوير منفصلة عن الإنتاج.

متغيرات بيئة الخادم:

| المتغير | الاستخدام |
| --- | --- |
| RATE_LIMIT_SALT | سر عشوائي لتجزئة معرف الشبكة وحدود المحاولات. |
| PUBLIC_FORM_ORIGIN | https://7madybar.github.io؛ يتيح CORS فقط لـ POST /api/challenge وPOST /api/submit. |
| TEAM_CODE_PEPPER | سر عشوائي لا يقل عن 32 حرفاً لحساب HMAC لرموز الفريق. احتفظ به ثابتاً؛ تغييره يبطل كل الرموز الحالية. |
| INITIAL_ADMIN_EMAIL | معرّف أول مدير محفوظ على الخادم؛ لا يحتاج إلى تسجيل حساب خارجي. |
| INITIAL_ADMIN_CODE_HASH | HMAC-SHA256 لرمز المدير الأول، ويستهلك للتهيئة مرة واحدة فقط. لا تضع الرمز نفسه في الشيفرة. |

احفظ قيم الإنتاج في إعدادات أسرار Sites. .env.example يوضح الأسماء فقط. لا ترفع .dev.vars أو الأسرار أو قواعد البيانات المحلية إلى GitHub.

لتوليد رمز المدير الأول وتجزئته محلياً في الطرفية، دون حفظه في المصدر، استخدم متغيراً سرياً TEAM_CODE_PEPPER ثم احسب HMAC على النص team-code: متبوعاً بالرمز بعد إزالة المسافات والشرطات والبادئة VG. مثال التطوير في الفحوص يستخدم VG-TESTA-TESTB-TESTC-TESTD فقط، ولا يُستخدم في الإنتاج.

## دخول الفريق وإدارته

1. افتح /admin وأدخل رمز المدير الذي استلمته بشكل خاص. لا يلزم تسجيل دخول إلى ChatGPT.
2. من إدارة الفريق أضف الاسم وحدد صلاحية عضو أو مدير. يصدر الخادم رمزاً عشوائياً مستقلاً يظهر مرة واحدة؛ انسخه وسلّمه لصاحبه.
3. الرمز غير محفوظ كنص صريح. إذا فُقد، أصدر رمزاً جديداً؛ يُلغى السابق وجلسات العضو الأخرى فوراً. تبقى جلسة المدير الحالية عند تجديد رمزه الخاص حتى يستطيع نسخ البديل.
4. يمكن إيقاف عضو أو تغيير دوره. الإيقاف يسحب جلساته، وتتحقق كل قراءة/كتابة من العضوية الحالية على الخادم.
5. تنتهي الجلسة بعد 8 ساعات، وتحفظ في Cookie من نوع Secure وHttpOnly وSameSite=Lax. تسجيل الخروج يلغيها على الخادم.
6. بعد أول تهيئة يمكن إزالة INITIAL_ADMIN_CODE_HASH من البيئة وإعادة النشر. الرمز الحالي محفوظ كتجزئة في DB، ولا تعيد التهيئة إحياء حساب موقوف.

## التطوير المحلي والفحوص

انسخ .env.example إلى .dev.vars واضبط قيماً محلية منفصلة. ابنِ الخادم باستخدام npm run build ثم طبق ملفات SQL في drizzle بالترتيب، مرة واحدة فقط لكل قاعدة:

```powershell
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_harsh_drax.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0001_flippant_calypso.sql
npm run dev
```

الفحوص: npx tsc --noEmit، ثم node tests/integration.mjs http://127.0.0.1:5173. فحوص التكامل مخصصة لقاعدة تطوير فقط، بمعرف المدير seedy@sites.test ورمز الاختبار المذكور أعلاه.

## الأمان والخصوصية

كل قراءة للرسائل أو التعليقات، وكل تغيير في الحالات والأعضاء، يتطلب جلسة صحيحة وعضوية مفعّلة؛ إدارة الرموز تتطلب مديراً. CORS لا يتيح قراءة أي بيانات خاصة، ولا يتيح تسجيل الدخول من GitHub. الدخول واللوحة يفتحان على نطاق الخادم فقط.

الحماية من الإزعاج: حد للرسائل والمحاولات وتذاكر التحقق، حقل فخ، تذكرة عشوائية مرتبطة بتجزئة الشبكة، حد أدنى زمني، تحقق من Origin، حدود أحجام الطلبات والحقول، ومعرف فريد لمنع تكرار الإرسال. حد الدخول 10 محاولات لكل شبكة في 10 دقائق.

لا يستخدم التطبيق localStorage كقاعدة رسائل أو لحفظ رموز الدخول. الاسم اختياري ولا يعني إخفاء الهوية الكامل. لا يوجد تشفير طرف إلى طرف. حافظ على سرية رموز الفريق؛ أي شخص يحصل على رمز يستطيع استخدام صلاحية صاحبه حتى إيقافه أو تدويره.

## المالك والمدير والعضو

المالك هو الحساب الأصلي الذي عُرّف عند تهيئة الموقع؛ يُحدّث دوره مرة واحدة دون تغيير رمزه أو إعادة تفعيل حساب موقوف. لا توجد واجهة عامة لإنشاء مالك آخر أو تغيير صلاحية المالك.

- المالك يدير المديرين والأعضاء، ويستطيع تجديد رمزه الخاص. لا يمكن إيقافه أو تغيير صلاحية المالك من لوحة الإدارة.
- المدير يستطيع إضافة مدير أو عضو، وتغيير صلاحياتهم أو إيقافهم وتجديد رموزهم. يحظر الخادم أي تغيير لحساب المالك أو رمزه، بصرف النظر عن الأزرار الظاهرة في الواجهة.
- العضو يستطيع قراءة الرسائل ومناقشتها وتحديث حالاتها، ويشاهد قائمة الفريق وأسماءهم وصلاحياتهم وحالاتهم. لا يستطيع إضافة أشخاص أو تعديلهم أو إصدار رموز.
- قائمة الفريق لا تعيد بريد الأعضاء أو تجزئات الرموز أو أسرار الجلسات؛ تستخدم معرفات عامة للإجراءات المسموحة.

## عنوان لوحة الفريق على GitHub

رابط الفريق الظاهر هو https://7madybar.github.io/---------------------/team/ . تعرض هذه الصفحة لوحة الخادم داخل إطار مخصص. يظل الخادم وقاعدة البيانات على استضافتهما الحالية؛ هذا عرض للوحة داخل نطاق GitHub وليس نقلاً لخادم التطبيق إلى GitHub Pages.

تستخدم جلسة الإطار Cookie مستقلة Secure وHttpOnly وSameSite=None وPartitioned، لمدة ثماني ساعات. تبقى الجلسة المباشرة على نطاق الخادم SameSite=Lax. لا تُحفظ الرموز أو الجلسات في localStorage، ولا يُفتح CORS لقراءة الرسائل أو لإدارة الفريق أو تسجيل الدخول. يحدد CSP الآباء المسموح لهم بتضمين اللوحة بنطاق GitHub الخاص بالموقع ونفس نطاق الخادم فقط.

يتطلب دخول الإطار متصفحاً محدثاً يدعم حفظ الجلسة المعزولة. تتحقق واجهة الدخول من حفظ الجلسة قبل عرض نجاح الدخول؛ عند المنع تظهر رسالة واضحة مع خيار فتح اللوحة المستقلة. التنقل إلى صندوق التواصل يعود إلى صفحة GitHub الرئيسية.

الأمر npm run build:pages يبني الآن index.html وteam/index.html وpages-assets. يجب رفع هذه الملفات مع المصدر عند نشر تغيير للرابط.
